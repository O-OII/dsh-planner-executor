# 无需手改 YAML 的配置页

[English](configuration.md) · [项目说明](../README.zh-CN.md) · [DS 执行完整契约](ds-execution.zh-CN.md)

## 从哪里进入

启用本组合包后，打开 **插件 → DSH Agent Activity（代理活动面板）**。配置直接显示在组合包详情页的说明与组件列表之间，**不是全局“设置”中的新分类**，也不必另装配置插件。浏览器代码以 `dsh-agent-activity` 为 key 注册官方 `plugins.bundle.config` 扩展点。

若所用 DSH 缺少该扩展点，只会没有配置页，不阻塞原活动浮窗。组合包关闭时没有浏览器配置贡献。本次更新不会自动替换你以前维护的本地版，不要同时启用两个副本。

## 活动面板卡片

选择 **跟随 DSH、English、简体中文**，再保存面板设置。语言由官方 `subagent-activity` Settings 命名空间持久化。只编辑选择不会立即改变浮窗，Host 确认保存后才生效。跟随 DSH 时，DSH 语言切换会翻译配置页与浮窗，但不会清空未保存编辑。

低层客户端 `config.locale` 仅作首次读取前的回退；取得合法 Host 命名空间后以 Host Settings 为准。路由错误语言独立配置；Host 的 `auto` 目前使用英文，并非浏览器 DSH 语言。

## DS 执行卡片

1. 添加至少一组**触发主模型 provider/model**。两项都是精确标识，必须同时匹配主代理路由。可以增删多组条件，父 reasoning effort 不参与匹配。
2. 设置**执行目标 provider/model**。优先从官方模型目录选取标识；目录缺失、不可用、部分失败或未列出你的路由时，可以手动输入。不会把显示名称作为配置标识保存。
3. **推理强度**默认留空，仅当你确认精确目标支持时填写。目录建议不等于授权或能力验证，手填值不保证受支持。
4. 选择路由错误语言。准备配置时可以保持关闭；有有效触发条件和目标后才能开启策略。
5. 保存 DS 卡片。`enabled`、`parentRoutes`、`targetRoute`、`locale` 一次提交为完整官方 Settings 更新，避免中间状态“已经开启但没有目标”。

初始空配置可以在关闭时保存；非空但不完整的条件行、必填标识为空、标识包含空白、只填写一半的执行目标会报校验错误。不提供 API Key 输入框，凭据应通过 DSH 自身 provider 管理配置。

**DS 是界面简称，不限定 DeepSeek。** 策略只影响后续匹配的新委派，不迁移已有子代理、在途调用或后续消息。语法校验与保存成功都不证明目标存在、有权限、价格合适或支持所填推理强度；执行路由的权威解析仍由新委派时的 Host preflight 完成。

## 保存、取消与同步

- 打开页面和编辑不会写入。每张卡片有独立草稿与明确的保存／丢弃控制，离开页面会丢弃未保存编辑。
- 两张卡片各自保存到两个命名空间，**不伪装成跨命名空间原子事务**；保存面板语言不会顺便提交路由草稿。
- 当前状态来自 Host 确认值，不根据尚未保存的启用勾选推断。关闭失败仍显示已确认的开启，并明确报错。
- 成功回执更新相应卡片与浮窗；通知按 revision 过滤，旧读取或旧回执不能回滚新状态。
- 其他窗口修改或 revision 冲突时保留草稿并阻止过期保存。先核对最新 Host 状态，再显式丢弃／重载或基于新状态重新确认草稿，不自动重放旧保存意图。
- 断线重连会作废在途请求，旧回执不能迟到报成功。草稿保留，供对照重连后的 Host 状态重新检查。
- Settings 明确返回不可写时，禁用保存并展示原因。另一张卡片和浮窗不会把服务缺失冒充为“已关闭”。

### home／命令行覆盖的边界

官方命名空间描述**没有逐字段覆盖／可写标志**，因此页面不能承诺在保存前就预判 home patch 或 CLI overlay。官方 ConfigEditor 会在持久化前拒绝这类写入；页面展示拒写、保留草稿，不宣称成功。请在表单外处理更高优先级覆盖，再明确重新读取、核对后保存；页面不会删除或绕过覆盖。

见[可复现测试说明](testing.md)。合成浏览器验证使用真实表单与浮窗代码、可控 Settings 权威；单独的隔离官方 Settings／ConfigEditor 检查验证持久化与拒写，不接触现用 profile。两者都不是已安装 DSH 的真实传输／导航全链路验收。配置和运行夹具不需要调用收费模型。
